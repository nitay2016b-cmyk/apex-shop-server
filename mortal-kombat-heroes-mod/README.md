# Mortal Kombat Heroes – מוד למיינקראפט

מוד **Fabric** ל-**Minecraft 1.21.1**. כל הפריטים נמצאים בטאב "גיבורי מורטל קומבט" במצב קריאטיב (אפשר גם לבנות אותם בשולחן עבודה).

## איך מתקינים
1. מתקינים את [Fabric Loader](https://fabricmc.net/use/installer/) ל-1.21.1.
2. מורידים את [Fabric API](https://modrinth.com/mod/fabric-api) ל-1.21.1 ושמים בתיקיית `mods`.
3. מורידים את `mortal-kombat-heroes-1.0.0.jar` (מ-GitHub → Actions → הבנייה האחרונה → Artifacts) ושמים גם אותו בתיקיית `mods`.
4. בשרת: שמים את אותם שני קבצים גם בתיקיית `mods` של השרת.

## הפקדים
- **קליק ימני** = התקפה 1
- **שיפט + קליק ימני** = התקפה 2

| פריט | קליק ימני | שיפט + קליק ימני |
|---|---|---|
| הידיים של סקורפיון | חנית ושרשרת: **GET OVER HERE!** מושך את היריב אליך | אגרוף אש חזק ששורף את היריב |
| הידיים של סאב זירו | מקפיא את היריב ל-**5 שניות** (לא זז ולא קופץ) | דקירת קרח שמורידה **5 לבבות** |
| יורה הקורים של ספיידרמן | קורים בפנים: היריב **לא רואה ולא זז 5 שניות** | להחזיק: יורה קור לבלוק ומתנדנד עליו. עוזבים כדי לעוף קדימה |
| הכפפה של איירון מן | קרן ריפולסור | טיל שמתפוצץ (לא הורס בלוקים) |
| כפפת האינסוף של תאנוס | שימוש באבן הנבחרת | החלפת אבן |

### האבנים של כפפת האינסוף
- 🟣 **כוח** – פיצוץ סגול שמעיף ופוגע בכל מי שמסביב למקום שאתה מכוון
- 🔵 **חלל** – שיגור למקום שאתה מסתכל עליו
- 🔴 **מציאות** – הופך מפלצות לתרנגולות (שחקנים מקבלים סחרחורת ועיוורון)
- 🟠 **נשמה** – שואב חיים מהיריב ומרפא אותך
- 🟢 **זמן** – עוצר את הזמן לכולם מסביבך ל-5 שניות
- 🟡 **תודעה** – המפלצות מסביב נלחמות אחת בשנייה
- ⚪ **הנקישה** – חצי מהמפלצות ברדיוס 64 בלוקים הופכות לאבק

## החליפות
לכל גיבור יש חליפה של 4 חלקים (קסדה, חזה, מכנסיים, מגפיים). **הכוחות של החליפה עובדים רק כשלובשים את כל 4 החלקים של אותו גיבור.**

| חליפה | כוחות |
|---|---|
| סקורפיון | חסינות לאש, כוח |
| סאב זירו | הגנה, מהירות, אי אפשר להקפיא אותו |
| ספיידרמן | **טיפוס על קירות** (הולכים לתוך הקיר כדי לטפס, שיפט כדי להיצמד), קפיצה גבוהה, מהירות, בלי נזק נפילה, אי אפשר לתפוס אותו בקורים |
| איירון מן | **טיסה** (לחיצה כפולה על רווח), ראייה בלילה, חסינות לאש, הגנה, והכפפה יורה חזק יותר |
| תאנוס | כוח II והגנה II |

## מתכונים (שולחן עבודה)
- **חליפות**: הצורה הרגילה של שריון, מ: סקורפיון = מוט בלייז, סאב זירו = קרח כחול, ספיידרמן = קורי עכביש, איירון מן = בלוק ברזל, תאנוס = בלוק זהב.
- **הידיים של סקורפיון**: מוט בלייז + שרשרת + מטיל זהב + עור + חרב ברזל
- **הידיים של סאב זירו**: קרח כחול + קרח דחוס + יהלום + עור + חרב ברזל
- **יורה קורים**: 2 קורי עכביש + חוט + מטיל ברזל + רדסטון
- **כפפת איירון מן**: בלוק ברזל + מטיל זהב + בלוק רדסטון + יהלום
- **כפפת האינסוף**: בלוק זהב + כוכב נת'ר + יהלום + אמרלד + רסיס אמטיסט + רדסטון + לאפיס + אבקת בלייז

## בנייה לבד
```
./gradlew build
```
הקובץ יוצא ב-`build/libs/`. הטקסטורות נוצרות עם `python3 tools/gen_assets.py`.
