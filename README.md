# AI Video Studio

אפליקציה שמשלבת חוויית ספרייה בסגנון YouTube עם חוויית עבודה בסגנון Google AI Studio:
מעלים סרטון, בוחרים או מגדירים **פורמט עריכה** (System Instructions ל-AI — יחס תמונה,
אורך יעד, טון, כתוביות, מוזיקה, הנחיות חופשיות), ה-AI "עורך" את הסרטון לפי ההנחיות
ומציג את תהליך העריכה בזמן אמת, ובסיום שואל אם להעלות את הסרטון ישירות ליוטיוב.

## הרצה מקומית

```bash
npm install
npm run dev
```

האפליקציה תעלה בכתובת http://localhost:3000.

כל הנתונים (וידאו שהועלה, פורמטים, פרויקטים, טוקן YouTube) נשמרים מקומית בתיקיית
`data/` (לא עולה ל-git).

## מבנה הזרימה

1. **`/upload`** — העלאת קובץ וידאו ובחירת/יצירת פורמט עריכה.
2. **`/formats`** — ניהול פורמטים שמורים לשימוש חוזר.
3. **`/studio/[id]`** — "הסטודיו": מריצים את עריכת ה-AI, רואים את שלבי התהליך בזמן
   אמת, וצופים בתוצאה.
4. **`/studio/[id]/publish`** — לאחר שהעריכה מוכנה, האפליקציה שואלת אם להעלות ישר
   ליוטיוב, עם כותרת/תיאור/תגיות שה-AI הציע ואפשר לערוך.
5. **`/settings`** — חיבור/ניתוק חשבון YouTube.

## מגבלות הגרסה הנוכחית (חשוב לדעת)

- **עריכת הווידאו היא הדגמה (mock).** התהליך מדמה שלבי עריכת AI אמיתיים (ניתוח,
  זיהוי רגעים, חיתוך, כתוביות, מוזיקה) אבל לא מריץ מודל וידאו-AI אמיתי על הקובץ —
  אין כאן חיבור ל-ffmpeg או למודל ג'נרטיבי. כדי לחבר מנוע אמיתי (Google Veo, Runway,
  שירות עריכה מבוסס-ffmpeg וכו') יש להחליף את הלוגיקה ב-`src/lib/pipeline.ts`.
- **העלאה ליוטיוב היא אמיתית**, דרך YouTube Data API v3, ודורשת הגדרת OAuth (ראו
  למטה).

## הגדרת חיבור YouTube (להעלאה אמיתית)

1. ב-[Google Cloud Console](https://console.cloud.google.com/) צרו פרויקט, הפעילו
   את **YouTube Data API v3**, וצרו פרטי **OAuth client ID** מסוג "Web application".
2. הוסיפו ל-Authorized redirect URIs את הכתובת:
   `http://localhost:3000/api/auth/youtube/callback` (או הדומיין שלכם בפרודקשן).
3. העתיקו את `.env.example` לקובץ `.env.local` ומלאו:
   ```
   YOUTUBE_CLIENT_ID=...
   YOUTUBE_CLIENT_SECRET=...
   YOUTUBE_REDIRECT_URI=http://localhost:3000/api/auth/youtube/callback
   ```
4. הפעילו מחדש את השרת, גשו ל-`/settings` ולחצו "התחברות לחשבון YouTube".

בלי הגדרה זו, כל שאר האפליקציה (העלאה, עריכה, פורמטים) עובדת רגיל — רק ההעלאה
בפועל ליוטיוב תישאר חסומה עם הודעה מתאימה.
